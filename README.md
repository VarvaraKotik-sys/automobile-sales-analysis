# Automobile Sales Analysis

Data analysis and interactive dashboard exploring automobile sales trends, built with Python.

Final project for the **Data Visualization with Python** course (NPower Canada).

## What's inside

- **Part 1 — Exploratory analysis**: sales trends with matplotlib, seaborn and Plotly — yearly and monthly sales, breakdowns by vehicle type, and the impact of recession, unemployment and advertising spend.
- **Part 2 — Interactive dashboard** (`automobile_sales_dashboard.py`): a Plotly Dash app with two report types —
  - *Yearly Statistics*: average yearly sales, monthly totals, sales and ad spend by vehicle type
  - *Recession Period Statistics*: sales during recessions, ad spend share, effect of unemployment

## Tech stack

Python · pandas · matplotlib · seaborn · Plotly · Dash

## Data

Monthly US automobile sales (1980–2023) with recession flags, unemployment rate and advertising expenditure.
